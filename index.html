Aponte para o quadro

  1. Toque em Iniciar.
  2. O celular vai pedir permissão para usar a câmera. Toque em Permitir.

    A câmera serve só para reconhecer o quadro: nenhuma foto ou vídeo é salvo ou enviado.

  3. Aponte a câmera para o quadro: a imagem vai ganhar vida.
  4. Toque no botão de play para ouvir a música e acompanhar a letra.
